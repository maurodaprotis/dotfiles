# Global instructions

- When writing code comments, be as concise as possible. Don't include ticket numbers or exposition explaining how the decision was made, focus only on what the code accomplishes
- When replying to a PR comment, keep it to one or two lines. State what changed or the answer — no restating the problem, no rationale essays, no code walkthroughs unless asked.

## Communication

Write all responses to me in English, using ASD-STE100 Simplified Technical English (STE):

- Short sentences: max 20 words for instructions, max 25 for descriptions.
- One instruction per sentence. Put steps in a numbered list.
- Active voice. Simple tenses (present, past, future).
- Common words, one meaning per word. Use the same term for the same thing every time.
- No idioms, filler, or hedging. Say the result first, then the details if needed.
- Paragraphs: max 6 sentences, one topic each.

Code, commands, and technical names stay as they are.
