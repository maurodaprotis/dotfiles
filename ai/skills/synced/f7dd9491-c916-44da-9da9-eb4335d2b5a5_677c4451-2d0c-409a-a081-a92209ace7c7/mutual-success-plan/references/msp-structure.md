# Mutual Success Plan Structure Reference

## Document Sections (in order)

### 1. Purpose
Brief 1-2 sentence description of the pilot relationship. Explains this is a short-term pilot to explore Lev's platform, assess workflow fit, and determine broader adoption potential. Emphasizes no commitment to full rollout.

### 2. Overview Table
Two-column table (Milestone | Details):
- Start Date: Specific date
- Length: Duration in days (typically 90-120)
- Decision Date: Date for Go/No-Go decision

### 3. Stakeholders Table
Three-column table (Party | Role | Name/Details):

**Lev roles (always include):**
- Account Lead
- Account Manager

**Customer roles (customize per deal):**
- Project Owner(s)
- Executive Sponsor
- Technical Lead (if applicable)
- Pilot Users

### 4. Phase 1: Pilot / Proof of Concept

**(a) Scope Table** - Two columns (Item | Details):
- User(s): Named pilot participants
- Cost: Pricing structure
- Access Includes: Features available

**(b) Primary Use Cases** - Bulleted list of 3-5 specific use cases the customer will evaluate

**(c) Success Criteria** - Bulleted list of measurable outcomes:
- Lender/contact accuracy
- Time savings metrics
- Workflow improvements
- Platform usability

**(d) Outcome** - Brief statement about go/no-go decision

### 5. Phase 2: Proof of Scale (if applicable)

**(a) Overview Table** - Same structure as Phase 1 Overview:
- Timeline
- Participants (expanded team)
- Decision Date
- Cost structure (tiered pricing)
- Term

**(b) Success Criteria** - Expanded metrics for multi-team adoption

**(c) Outcome** - Leadership decision options

### 6. Phase 3: Full Deployment (Future State)

**(a) Goal** - Brief description of company-wide rollout vision

**(b) Success Criteria** - Institutional-level outcomes:
- Full institutional adoption
- Unified/standardized processes
- Long-term platform integration

### 7. Key Milestones Table
Five-column table (Milestone | Description | Owner | Target Date | Status):

Standard milestones:
- Legal & Security Review
- Introduction Call / Kickoff
- Pilot Launch & Onboarding
- Training Sessions
- Bi-Weekly Check-Ins (Ongoing)
- Mid-Pilot Review
- Final Review
- Go/No-Go Decision

### 8. Pilot Exit Criteria (optional)
Numbered list of conditions for Phase 1 success:
- Success criteria substantially met
- Clear value demonstrated
- Commercial alignment for next phase

## Content Guidelines

### Stakeholder Names
- Always use full names
- Include titles/roles in parentheses when helpful
- For pilot users, group by office/location

### Pricing Formats
- Platform Access Fee: $X,XXX/month (includes N users)
- Additional Users: $XXX/user/month
- Contract Agreement: $XX,XXX ($X,XXX/month) annual agreement
- Always note minimum commitment term

### Success Criteria Writing
- Use measurable language where possible (percentages, counts)
- Focus on outcomes not activities
- Common metrics:
  - Weekly active usage rates (e.g., 80%+)
  - Deals launched per office
  - Time savings in specific workflows
  - User feedback/satisfaction

### Timeline Conventions
- Use "Start Date + X days" format for relative dates
- Use specific dates (Month Day, Year) for absolute dates
- Standard phases: 60-90 days each

### Tone
- Professional, concise
- Avoid marketing language
- Focus on mutual accountability
- Emphasize partnership over vendor relationship
